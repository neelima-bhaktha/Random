A growing collection of small, curiosity-driven projects exploring ideas in computer vision, machine learning, and interactive systems.

This repository is meant to be a playground — a space to test ideas quickly, learn by building, and iterate without the pressure of polishing everything into a final product.
##📌 Purpose

This repository exists to:

Experiment with CV and ML concepts hands-on

Explore interactive and visual ideas

Build intuition through rapid prototyping

Document learning through code

Projects here prioritize process over perfection.

---


##🧠 What’s Inside

You’ll find a mix of:

Computer vision demos and experiments

Gesture and face-based interaction ideas

Small ML prototypes

Visual and playful explorations

Each project lives in its own folder and can be explored independently.

---

##🛠️ Technologies

Technologies vary by project, but commonly include:

Python

OpenCV

MediaPipe

NumPy

Other ML / CV libraries

Project-specific dependencies are documented locally where needed.

##📂 Repository Structure

A typical layout looks like:

/
├── project_name_1/
│   ├── main.py
│   ├── assets/
│   └── README.md
│
├── project_name_2/

│   └── README.md
│

Each folder represents an independent experiment.

##▶️ Running Projects

General workflow:

Navigate into a project folder

Set up a virtual environment (optional but recommended)

Install required dependencies

Run the main script

Refer to the project’s own README for exact instructions.
